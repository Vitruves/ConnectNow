Mac struggling to connect to public Wi-Fi? Here’s the fix.

Hotel, train station, café, airport: you’re connected, but nothing loads and the login page never shows up. ConnectNow finds it and opens it.

Download for Mac View on GitHub

Free and open source. The app isn’t notarized: the first time, right-click it and choose Open.

Why

Connected, but offline.

macOS only opens the Wi-Fi login window when its own check gets redirected by the network. Plenty of ordinary settings stop that from happening. ConnectNow looks for the page in other ways, so it works even when macOS gives up.

  • vpnA VPN or iCloud Private RelayYour traffic leaves through the tunnel, so the hotspot never gets to redirect it.
  • filterA firewall, ad blocker or custom DNSSomething on your Mac filters the very requests the network needs to see.
  • routeA web proxy or another connectionEthernet or your iPhone’s hotspot takes priority over the Wi-Fi.
  • portalA picky portalSome networks let Apple’s check through and block everything else.

Features

Finds the page. Opens it. Tells you what’s wrong.

  • findFinds the pageIt checks the addresses Apple, Google, Firefox and Microsoft use, asks the network directly, and goes around your VPN when it has to.
  • openOpens itThe login page opens in its own window, with the real address always visible. Nothing is kept once you leave the network.
  • explainTells you what’s wrongVPN, proxy, private Wi-Fi address, a filter running in the background: you see what’s in the way and what to do about it.
  • fixFixes the usual suspectWhen the cause can be fixed for you, one click does it. Your settings come back as soon as you’re online.
  • watchKeeps watchIt rescans when the network changes and notices when your session expires, so the login page comes back on its own.
  • privateNo account, no trackingIt only contacts the connectivity checks, the login page, and GitHub to look for updates.

CLI

Also in the terminal.

Right-click in the ConnectNow window and choose Install Command-Line Tool. connectnow status exits with a code you can test in scripts.

$ connectnow          # status, login page, what blocks it
$ connectnow watch    # one line per change
$ connectnow open     # open the login page
$ connectnow --json   # for scripts

Keep it in your Applications folder for the next trip.

Open it whenever a network won’t let you in.
